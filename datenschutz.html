3. Welche Google-Daten die App verwendet

Die App nutzt die Anmeldung mit Google und fordert folgende Berechtigungen an:

  • Grundlegende Kontodaten (Name, E-Mail-Adresse, Profilbild): um anzuzeigen, mit welchem Konto die App verbunden ist.
  • Google Drive, nur von der App angelegte Dateien (drive.file): Die App legt eine Tabelle für den Weinbestand sowie einen Ordner für Fotos von Weinetiketten an und liest und bearbeitet ausschließlich diese Dateien. Auf andere Dateien im Google Drive hat die App keinen Zugriff.

4. Zweck der Verarbeitung

Die Daten werden ausschließlich verwendet, um die Funktionen der App bereitzustellen, also den Weinbestand zu speichern, anzuzeigen und auszuwerten. Es findet keine Auswertung zu Werbe- oder Analysezwecken statt.

5. Speicherort

  • Im eigenen Google Drive der angemeldeten Person.
  • Lokal auf dem Gerät als Zwischenspeicher, damit die App auch ohne Netz funktioniert.

Die App betreibt keinen eigenen Server und überträgt keine Daten an den Entwickler.

6. Weitergabe an Dritte

Daten werden nicht verkauft und nicht zu Werbezwecken weitergegeben. Eine Übermittlung erfolgt nur in folgendem Fall:

  • Google Gemini API: Wenn die Person ein Etikett oder einen Kaufbeleg fotografiert und die Erkennung ausdrücklich startet, wird das Foto an die Gemini API von Google gesendet, um Angaben wie Weingut, Jahrgang oder Preis auszulesen. Dafür gelten die Nutzungsbedingungen und Datenschutzhinweise der Gemini API.

Google-Konto- und Drive-Daten werden nicht an die Gemini API übermittelt.

7. Einhaltung der Google-Richtlinien

Die Nutzung und Übertragung von Informationen, die AiOn von Google-APIs erhält, an andere Apps erfolgt gemäß der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

8. Zugriff widerrufen und Daten löschen

  • Der Zugriff der App auf das Google-Konto lässt sich jederzeit unter myaccount.google.com/connections widerrufen.
  • Die von der App angelegten Dateien können direkt im Google Drive gelöscht werden.
  • Beim Deinstallieren der App werden die lokal gespeicherten Daten vom Gerät entfernt.

9. Diese Website

Diese Website wird über GitHub Pages (GitHub, Inc.) bereitgestellt. GitHub kann beim Aufruf technische Daten wie die IP-Adresse in Server-Logs verarbeiten. Diese Website setzt keine Cookies, lädt keine externen Schriften und verwendet kein Tracking.
